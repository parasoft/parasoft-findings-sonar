# Parasoft Findings for SonarQube

Parasoft Findings enables you to visualize static analysis, functional test results, unit test results, and code coverage results generated by Parasoft products in SonarQube. It grants SonarQube the ability to analyze data from Parasoft XML reports and use it to report bugs, vulnerabilities, functional test results, unit test results, code coverage or code smells from within SonarQube. Results can be conveniently viewed in SonarQube. Navigation to rule documentation is also available.

For documentation please visit the link [Parasoft Findings for SonarQube](https://docs.parasoft.com/display/FINDS/Parasoft+Findings+for+SonarQube) 

## SOAtest transformation regression tests

Run from the repository root with JDK 17 and Maven:

```sh
mvn test-compile org.apache.maven.plugins:maven-surefire-plugin:3.1.0:test -Dtest=SoatestXunitTransformationTest,SOAtestSensorTest
```

The tests transform the six local reports in `src/test/resources/soatest/regression` using the plugin's actual stylesheet and the existing Saxon dependency. They check testcase and failure counts, case association, message fallbacks, and diagnostic details without a SOAtest installation, license, or running service.

The reports originate from the sanitized canonical fixtures in Parasoft's XSLTTemplates project. `SOAtest_functional_execution_violations.xml` and `association_edges.xml` are synthetic regression inputs; `soatest_visual_difference.xml` and the three `soatest_parabank_change_impact_*.xml` files are sanitized report captures. All six fixtures are copied locally so these tests have no dependency on another checkout.
